# Callix

An AI voice agent for inbound call handling, built as a portfolio project
and themed as a salon receptionist.

## Features

- Real-time voice conversation over the browser, no app or download needed
- Understands what the caller wants and routes the conversation accordingly
- Answers questions about the business using its own knowledge base
- Books, reschedules, and cancels appointments
- Detects booking conflicts before confirming a new appointment
- Escalates to a human when it can't help
- Saves every call's transcript and any appointments made during it
- Read-only API for browsing past calls and appointments
